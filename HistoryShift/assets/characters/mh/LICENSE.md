# Realistic characters (MakeHuman / MPFB2 — CC0)

These models were generated headlessly by `tools/make_humans.py` with Blender 5.1 (bpy) and the MPFB2 add-on,
using the MakeHuman base mesh, targets, skeleton ("game_engine") and the MakeHuman system assets pack
(skins, eyes, eyebrows, eyelashes, hair, clothes, shoes).

- MPFB2 assets: CC0 1.0 — https://github.com/makehumancommunity/mpfb2 (LICENSE.ASSETS.md)
- MakeHuman system assets: CC0 1.0 — https://static.makehumancommunity.org/assets/assetpacks/makehuman_system_assets.html

Animations come from KayKit Character Animations (CC0) and are retargeted at import time via
`assets/characters/bonemap_*.tres` (see `tools/setup_retarget.gd`).
